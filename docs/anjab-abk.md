## Hasil analisis lampiran

## Pembobotan variabel dinas

Sheet PERHITUNGAN memakai tipe dinas A/B/C/D dengan skor 100/75/50/25, bobot tipe 50%, wilayah 30%, unit pelayanan 20%. Batas wilayah: 0–10 = 25; 11–20 = 50; 21–30 = 75; ≥31 = 100. Batas unit pelayanan: 0 = 25; 1–3 = 50; 4–9 = 75; ≥10 = 100.

Input awal A, 31 wilayah, 2 unit pelayanan menghasilkan skor 90. Proporsi 25% untuk masing-masing Medik Veteriner, Paramedik Veteriner, Pengawas Bibit Ternak, dan Pengawas Mutu Pakan menghasilkan FLOOR(90 × 25%) = 22 per jabatan, total alokasi 88, sisa 2. Bezetting empat JF adalah 17; kekurangan terhadap alokasi 71. Angka F13−L13=73 pada sumber memakai skor 90, sehingga berbeda dengan kekurangan terhadap alokasi setelah FLOOR. Aplikasi menampilkan alokasi dan sisa secara terpisah.

Analis PSP berada di luar proporsi empat JF pada sheet PERHITUNGAN dan masuk rekap total melalui rincian ABK-nya. Referensi yang tertulis di PERHITUNGAN!A18 adalah Keputusan Direktur Jenderal Peternakan dan Kesehatan Hewan Nomor 04583/kpts/OT.100/F/04/2024. Parameter aplikasi mengikuti lampiran dan dapat diperbarui pengguna.

## Penggunaan aplikasi

Buka **Kepegawaian → Anjab-ABK**. Menu pertama **Total Semua Jabatan** memuat rekap lima jabatan dan pembobotan dinas. Menu berikutnya memuat Medvet, Paramedik, Wasbitnak, Wastukan, dan Analis PSP. Pilih jenjang, ubah volume/AK/pembagi atau usulan/bezetting/penempatan, lalu gunakan **Simpan perhitungan**. Pencarian dan pagination tidak mengubah himpunan butir yang dijumlahkan.

Data awal berasal dari lampiran 2026. Tahun lain dimulai dari nilai awal yang sama sampai pengguna menyimpan rencananya. Isian belum disimpan dipertahankan ketika berpindah menu di dalam Anjab-ABK; navigasi keluar dan pemulihan nilai sumber meminta konfirmasi. Data per tahun tidak saling menimpa. Versi yang sudah berubah ditolak dengan HTTP 409 agar penyimpanan pengguna lain tidak tertimpa.

Angka nol sah. Pembagi harus positif; volume dan AK tidak negatif; jumlah pegawai harus bilangan bulat. Input kosong/tidak valid tidak ditampilkan sebagai kebutuhan nol. Nilai kekurangan negatif dipertahankan sebagai kelebihan. Jenjang Pelaksana dan Pelaksana Lanjutan mengikuti penamaan lampiran.

## Penyimpanan dan akses

Katalog sumber disimpan di modul server dan diberikan hanya setelah otorisasi halaman. Menu dan API memerlukan izin `anjab-abk`; administrator mendapat akses sesuai katalog menu. Endpoint `GET/PUT /api/anjab-abk/[year]` membatasi payload 512 KB dan memvalidasi seluruh kunci jenjang, butir dan unit terhadap katalog server. Seluruh hasil diturunkan dari input tervalidasi; klien tidak mengirim hasil hitungan untuk disimpan.

Tabel `anjab_abk_plans` menyimpan tahun, input JSON, revisi dan metadata penyunting, dengan FK pengguna ON DELETE SET NULL. Tabel tercakup pada inventaris PostgreSQL/SQLite, backup lokal/Google Drive dan ekspor migrasi. Migrasi bersifat penambahan, RLS aktif, akses langsung anon/authenticated dicabut untuk mengikuti pola sesi kustom aplikasi.
